EC2 Live Overlay

Customer cards, won products, batch compare and the restyled comment table on EC2's live manager. Saved immediately; reload any open EC2 live tab to apply.

Live 💬 messages

The 💬 button on each customer in the live's comment list sends one of these straight to the customer's Messenger as a reply to their comment (Meta allows one per comment). {name} = the customer's Facebook name, {psid} = their PSID (e.g. https://ddherbs.com.my/cart/{psid} opens their cart). Order comments like A2+3 are never used. Saved as you type; open live tabs update by themselves. Needs the Analysis API Token (Payment receipts, below).

Balance / Note bar and inbox layout

Balances and notes are saved on the customer's Baserow row, so every agent sees the same ones. Every change is kept in the note log table.

On by default. Tightens the spacing (not the text size) of the parts of the inbox that are rarely clicked, so the messages and the customer panel get the room.

On by default. When a chat is opened (also Meta's auto-open on load) and the customer's last message has no staff reply after it, the chat is marked unread again with Meta's own "Mark as unread" — so the team only needs to open unread chats. Automations never count as a reply. Chats still waiting for a reply are tinted light red in the conversation list. To close a chat without replying, react ❤️ (or any reaction) to the customer's last message.

ManyChat API Token

Used to search ManyChat subscribers by name when looking up a customer's PSID.

Baserow

Customer lookups, the linked UID in the "Users" table, and the Balance / Note bar (Users table fields + the note log table). The token needs create + update on the Users table and create + read on the note log table.

AI Reply API

Off by default. The ↩ / ✨ AI Rewrite / 华语 · English bar above the reply box. Saved immediately; open inbox tabs update by themselves.

Backend that calls Gemini or ChatGPT to generate suggested replies. Exposes POST /ai/reply and returns { ok, text }.

Voice message transcripts

Gemini API key (Google AI Studio). When set, every voice message in the inbox gets a word-for-word transcript and 1× / 1.5× / 2× speed buttons underneath. Empty = off. Voice clips are sent to Google.

Payment receipts

Token of the message-analysis worker. When set, every customer photo or PDF that the worker read as a payment receipt gets a bar underneath: amount, bank, paid time, payee, reference and warnings (duplicate slip, not paid to DD, not successful). Only for customers linked in the panel. Empty = off.
